# Thundr RP

Build Thundr, an AI roleplay chat app inspired by Character.ai featuring a light neon blue and sleek dark/black aesthetic with speech bubbles.

Key features:
1. Character & World Builder: Create custom characters (avatar, description, greeting, personality traits, system prompt) and link them to user-created worlds/lorebooks.
2. User Personas: Allow users to create and switch between custom user personas with distinct names, descriptions, and preferences.
3. Interactive Chat Interface: Sleek text bubble design, ability to edit both user and AI messages, regenerate AI responses (with swiping/alternative generation history), and pin important messages.
4. Auto-Summary & Story Memory: Automatic or manual story summarizer that tracks key events and keeps context remembered in long chats.
5. Image Generator: Tool to generate character avatars and scene visual cards.
6. Open creative prompt options allowing unrestricted roleplay and storytelling configuration.
